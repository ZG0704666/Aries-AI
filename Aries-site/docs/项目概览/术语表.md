# 术语表

参考 DeepWiki Glossary，并按当前源码校准（2026-10-14）。术语用于定位职责，不代表功能在所有设备上均可用。

| 术语 | 在本项目中的含义 | 阅读入口 |
| --- | --- | --- |
| VLM | 理解图像与文本的模型，为界面观测提供推理能力 | [多模型接入](../多模型接入/多模型接入总览.md) |
| Agent | `UiAutomationAgent` 协调观测、推理、解析和执行循环 | [Agent 主循环](../自动化引擎/自动化%20Agent%20主循环.md) |
| ActionParser | 将模型输出解释为动作结构 | [动作解析器](../自动化引擎/动作解析器%20(ActionParser).md) |
| ActionExecutor | 按模式把动作分派给虚拟屏、Shizuku 或无障碍通道 | [动作执行器](../自动化引擎/动作执行器%20(ActionExecutor).md) |
| Shizuku | Binder 形式的系统交互桥接，需要服务和授权就绪 | [权限配置](../快速开始/环境与权限配置.md) |
| vdiso | 虚拟显示、帧采集、定向输入及焦点恢复相关实现 | [虚拟屏隔离](../虚拟屏隔离系统/虚拟屏完全隔离总览.md) |
| displayId | Android 显示屏标识，输入和观测必须对应目标显示屏 | [采集与 UI 树](../自动化引擎/屏幕采集与%20UI%20树提取.md) |
| MNN | 端侧模型推理运行时，当前预置 Qwen3.5-9B MNN 包 | [本地推理](../多模型接入/本地推理%20(MNN).md) |
| Sherpa-ncnn / ASR | 本地语音识别，将麦克风音频转换为文本 | [离线语音识别](../对话系统/离线语音识别%20(Sherpa-ncnn).md) |
| SSE | 远端接口流式返回增量内容的协议形式 | [流式 Markdown](../对话系统/流式%20Markdown%20渲染.md) |
| Koin | 管理应用依赖与对象作用域的 DI 框架 | [依赖注入](../技术架构/DI%20依赖注入%20(Koin).md) |
| runId | 单次自动化运行的身份，用于任务详情与结果路由 | [导航与路由](../技术架构/导航与路由系统.md) |
| 心跳 | 前台使用状态的遥测请求，不是聊天或截图上传 | [遥测心跳](../更新与分发/遥测心跳与%20Cloudflare%20Worker.md) |
| D1 | 遥测 Worker 使用的 Cloudflare 数据库 | [遥测心跳](../更新与分发/遥测心跳与%20Cloudflare%20Worker.md) |
| Token | 根据上下文可指模型计量单位、API 凭据或 UI 样式资源，三者不同 | [模型配置](../快速开始/API%20Key%20与模型配置.md) |

来源：[DeepWiki](https://deepwiki.com/ZG0704666/Aries-AI)。
