### 当前代码核对（2026-10-14）

本次核对覆盖应用入口与导航、自动化任务、模型接入、虚拟屏、持久化、设计系统、构建和分发文档，并扫描整个文档目录的路由与文件链接。实现说明以本地源码为准；旧 DeepWiki 索引不能替代当前代码。

- 当前开发版本为 `2.0.0 Alpha`（versionCode 21），Android 最低 API 30，compileSdk/targetSdk 36。
- 主界面为历史、主页、设置三页 Pager；任务详情和结果使用独立 `runId` 路由。
- 本地推理围绕 Qwen3.5-9B MNN 模型文件及就绪检测展开。
- `FloatingChatService` 已从当前源码移除。仍提及该类的章节已标记为历史说明，不能作为当前可用功能的依据。
- Gradle Wrapper 为 9.4.1，AGP 为 9.2.1，Kotlin 为 2.2.21；Java/Kotlin 字节码目标 11 与运行 Gradle 所需 JDK 是不同概念。
- 本轮仅做静态源码和文档一致性核对；当前执行环境缺少 Java，Gradle 测试未能启动，也没有进行真机兼容性或性能验证。
