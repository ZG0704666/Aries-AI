# 设置界面体系

设置入口由 `app/src/main/java/com/ai/phoneagent/ui/settings/SettingsRoute.kt` 编排，状态由 `SettingsViewModel` 提供。主页三页 Pager 的第三页嵌入设置，导航图也保留独立的 `settings` 路由。

## 页面与状态

`SettingsViewModel.SettingsPage` 包括 Home、ModelApi、Automation、Membership、Appearance、About；`AnimatedContent` 根据当前子页和前进/返回方向切换。子页返回先回设置根页，嵌入模式可通过 `onExitToChat` 返回主页。只有当前激活设置页处理子页返回和恢复逻辑。

| 页面 | 内容 |
|---|---|
| ModelApi | 模型模式、服务地址、模型名、连接测试、Aries 登录和本地模型下载 |
| Automation | 后台执行、Shizuku 交互、自动确认及控制台入口 |
| Appearance | 主题与外观配置 |
| Membership | 账号与当前模型展示 |
| About | 应用信息、更新及反馈入口 |

`AutomationPreferencesScreen` 与任务控制页共用 Activity 作用域的 `AutomationViewModel`。任务存在且未结束时禁用执行偏好开关，避免运行中更换执行条件；进入页面会刷新权限和执行状态。暂停请求仍属于未结束状态。

## 代码入口

- `app/src/main/java/com/ai/phoneagent/ui/settings/SettingsRoute.kt`
- `app/src/main/java/com/ai/phoneagent/ui/settings/AutomationPreferencesScreen.kt`
- `app/src/main/java/com/ai/phoneagent/viewmodel/SettingsViewModel.kt`

关于子页（About）承载应用信息、手动检查更新（`AboutViewModel`）与「任务反馈」入口；更新相关实现见 [应用内更新系统](../更新与分发/应用内更新系统.md)，反馈导出见 [反馈日志与导出](反馈日志与导出.md)。设置与引导共用 `:feature:settings` 模块的字符串资源（如 `feature/settings/src/main/res/values/onboarding_strings.xml` 中的协议与权限文案）。

详见 [模型模式切换与配置链路](../多模型接入/模型模式切换与配置链路.md) 和 [导航与路由系统](../技术架构/导航与路由系统.md)。
