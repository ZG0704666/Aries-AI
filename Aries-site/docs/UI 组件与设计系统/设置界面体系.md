# 设置、引导与导航界面

本页汇总设置页、首次引导、侧边栏抽屉和反馈日志入口的页面结构、状态与代码位置。

设置入口由 `app/src/main/java/com/ai/phoneagent/ui/settings/SettingsRoute.kt` 编排，状态由 `SettingsViewModel` 提供。主页三页 Pager 的第三页嵌入设置，导航图也保留独立的 `settings` 路由。

## 页面与状态

`SettingsViewModel.SettingsPage` 包括 Home、ModelApi、Automation、Membership、Appearance、About；`AnimatedContent` 根据当前子页和前进/返回方向切换。子页返回先回设置根页，嵌入模式可通过 `onExitToChat` 返回主页。只有当前激活设置页处理子页返回和恢复逻辑。

| 页面 | 内容 |
|---|---|
| ModelApi | 模型模式、服务地址、模型名、连接测试、Aries 登录和本地模型下载 |
| Automation | 后台执行、Shizuku 交互、自动确认及控制台入口 |
| Appearance | 主题与外观配置 |
| Membership | 账号与当前模型展示 |
| About | 应用信息、更新及反馈入口 |

`AutomationPreferencesScreen` 与任务控制页共用 Activity 作用域的 `AutomationViewModel`。任务存在且未结束时禁用执行偏好开关，避免运行中更换执行条件；进入页面会刷新权限和执行状态。暂停请求仍属于未结束状态。

## 代码入口

- `app/src/main/java/com/ai/phoneagent/ui/settings/SettingsRoute.kt`

## 引导页

当前 Compose 引导实现在 `app/src/main/java/com/ai/phoneagent/ui/onboarding/OnboardingScreen.kt`，入口是 `OnboardingRoute`。导航支持 `onboarding` 和 `onboarding?flow={flow}`。

### 三种流程

| 参数 | 流程 |
|---|---|
| 默认或未知值 | ONBOARDING，完整新手引导 |
| view_only | VIEW_ONLY，从协议页面开始阅读 |
| permission_only | PERMISSION_ONLY，从权限页面开始 |

完整流程包含欢迎、协议和权限步骤。协议面板的 `accepted` 初始为 false，需要用户勾选后继续；只读模式不要求重新接受协议。不能把“已打开协议页”视为接受协议。

权限页根据当前设备状态展示操作入口，涉及无障碍、悬浮窗、麦克风及 Shizuku 等能力。返回应用后需刷新状态；权限页展示的状态不替代执行任务时的运行前检查。

页面复用 `AriesPageTopBar`、`AriesGlassCard` 和 `AriesGlassButton`。历史的 `MainOnboardingOverlay` 文件仍存在，排查时应从实际调用入口确认使用路径，而不是只按文件名判断。

### 字符串资源

引导与权限文案集中在 `feature/settings/src/main/res/values/onboarding_strings.xml`：

- 欢迎步骤：`onboarding_welcome_title`（欢迎使用 Aries AI）、`onboarding_welcome_desc`、`onboarding_welcome_action`（继续）。
- 用户协议：`user_agreement_desc`、`user_agreement_action_next`，正文 `user_agreement_content`（CDATA HTML）覆盖 AGPL V3 授权、无担保与责任限制、用户责任、隐私政策、协议变更与终止、商业使用需书面授权（联系邮箱 zhangyongqi@njit.edu.cn）等条款。
- 权限面板（`perm_sheet_title`「完成首次设置」）：`perm_sheet_accessibility_*`（无障碍服务，用于点击/滑动/返回等自动化操作）、`perm_sheet_overlay_*`（悬浮窗显示）、`perm_sheet_microphone_*`（麦克风权限，用于语音输入与识别），以及 Shizuku 一键配置项（`perm_sheet_shizuku_*`，授权后自动补齐无障碍、悬浮窗和麦克风权限）。

相关：[环境与权限配置](../快速开始/环境与权限配置.md)。

## 侧边栏与抽屉

当前主界面的历史会话使用 `ConversationDrawer` 作为 `HomeScreen` 的历史页内容，并通过三页 `HorizontalPager` 在历史、主页和设置之间切换。名称保留了早期抽屉式导航的兼容语义；当前主布局不再由 `ModalNavigationDrawer` 包裹。

详细行为请参阅[主对话界面 (HomeScreen)](../对话系统/对话历史与会话管理.md)和[导航与路由系统](../技术架构/导航与路由系统.md)。

### 相关资源

- 历史会话文案位于 `app/src/main/res/values/history_strings.xml`：`history_dialog_title`（历史对话）、`history_empty`（暂无历史对话）、`history_new_chat`（新对话）、`history_current_chat_is_new`（当前已经是新对话）。
- `app/src/main/res/menu/top_app_bar.xml` 定义顶栏 `action_history` 项（图标 `@drawable/ic_history_24`，标题 `@string/ui_v2_history`，`showAsAction="ifRoom"`），作为历史页入口之一。
- `app/src/main/res/menu/drawer_menu.xml` 保留了传统抽屉菜单结构：不可勾选分组内含 `nav_automation`（标题 `@string/m3t_nav_automation`）与 `nav_about`（标题 `@string/m3t_nav_about`）两项。
- 抽屉相关尺寸与颜色 token（`m3t_drawer_*`，如头像 72dp、会话项圆角 20dp、scrim `#66000000`）定义在 `app/src/main/res/values/m3t.xml`，夜间值在 `values-night/m3t.xml`。

## 反馈日志

`app/src/main/java/com/ai/phoneagent/helper/FeedbackLogExporter.kt` 提供反馈包生成和系统分享，设置的关于页面调用该功能。

### 导出内容

`exportSanitizedBundle` 在 IO 调度器生成缓存目录 `feedback_exports` 下的 ZIP 文件：

| 文件 | 内容 |
|---|---|
| metadata.txt | 应用版本、设备、Android 版本和执行环境信息 |
| automation_last_result.txt | AutomationResultsRepository 中的最近任务结果 |
| logcat_current_process.txt | 当前应用进程的 Logcat |

导出前使用正则处理邮箱、手机号、Bearer 凭据以及部分头部、查询参数和 JSON 密钥字段。自动替换不是所有业务文本的完整匿名化，提交问题前仍应查看文件内容。

### 分享和排查

`shareBundle` 使用 FileProvider URI 和临时读权限，通过 Android 分享面板交给用户选择目标。导出文件不会因此自动上传。

报告问题时附上复现步骤、执行模式、模型、应用与系统版本、发生时间，以及是否开启虚拟屏。最近结果只代表仓储保存的那一次运行，不是完整任务历史。

详见 [反馈日志与问题排查](../常见问题与支持/故障排查指南.md)。
