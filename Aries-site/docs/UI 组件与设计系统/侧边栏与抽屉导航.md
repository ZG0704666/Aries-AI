# 侧边栏与抽屉导航

当前主界面的历史会话使用 `ConversationDrawer` 作为 `HomeScreen` 的历史页内容，并通过三页 `HorizontalPager` 在历史、主页和设置之间切换。名称保留了早期抽屉式导航的兼容语义；当前主布局不再由 `ModalNavigationDrawer` 包裹。

详细行为请参阅[主对话界面 (HomeScreen)](../对话系统/主对话界面%20(HomeScreen).md)和[导航与路由系统](../技术架构/导航与路由系统.md)。

## 相关资源

- 历史会话文案位于 `app/src/main/res/values/history_strings.xml`：`history_dialog_title`（历史对话）、`history_empty`（暂无历史对话）、`history_new_chat`（新对话）、`history_current_chat_is_new`（当前已经是新对话）。
- `app/src/main/res/menu/top_app_bar.xml` 定义顶栏 `action_history` 项（图标 `@drawable/ic_history_24`，标题 `@string/ui_v2_history`，`showAsAction="ifRoom"`），作为历史页入口之一。
- `app/src/main/res/menu/drawer_menu.xml` 保留了传统抽屉菜单结构：不可勾选分组内含 `nav_automation`（标题 `@string/m3t_nav_automation`）与 `nav_about`（标题 `@string/m3t_nav_about`）两项。
- 抽屉相关尺寸与颜色 token（`m3t_drawer_*`，如头像 72dp、会话项圆角 20dp、scrim `#66000000`）定义在 `app/src/main/res/values/m3t.xml`，夜间值在 `values-night/m3t.xml`。
