# 反馈日志与导出

`app/src/main/java/com/ai/phoneagent/helper/FeedbackLogExporter.kt` 提供反馈包生成和系统分享，设置的关于页面调用该功能。

## 导出内容

`exportSanitizedBundle` 在 IO 调度器生成缓存目录 `feedback_exports` 下的 ZIP 文件：

| 文件 | 内容 |
|---|---|
| metadata.txt | 应用版本、设备、Android 版本和执行环境信息 |
| automation_last_result.txt | AutomationResultsRepository 中的最近任务结果 |
| logcat_current_process.txt | 当前应用进程的 Logcat |

导出前使用正则处理邮箱、手机号、Bearer 凭据以及部分头部、查询参数和 JSON 密钥字段。自动替换不是所有业务文本的完整匿名化，提交问题前仍应查看文件内容。

## 分享和排查

`shareBundle` 使用 FileProvider URI 和临时读权限，通过 Android 分享面板交给用户选择目标。导出文件不会因此自动上传。

报告问题时附上复现步骤、执行模式、模型、应用与系统版本、发生时间，以及是否开启虚拟屏。最近结果只代表仓储保存的那一次运行，不是完整任务历史。

详见 [反馈日志与问题排查](../开发规范与工具/反馈日志与问题排查.md)。
